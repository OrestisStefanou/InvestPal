# Task Description
The goal of this task is to change the way we store the context of the user.

## What we currently do
We expose the UserContext model which basically stores the information we have for the user in a key value store way(user_profile field). We currently use MongoDb as the database to store this information

## Where we want to go
We want to move away from the UserContext data model. Instead we will introduce the concept of UserProfileNote similar to what we do with UserConversationNotes so instead of having a key value store for the user profile we will have an array of user profile notes. We are moving away from storing user_id as well since investPal project will migrate to become a single user project that will only expose mcp tools. We will use turso as the database to store the user profile notes. Below is the schema that the table should have

table name: user_profile_notes
columns:
- id -> uuid autogenerated
- note -> free text
- created_at -> datetime autogenerated
- outdated -> bool with default false

We need to create a new repos module(same level as the services one). In that module we should create a file called user_profile_notes.py where we will define a class that will be an abstraction on top of the table. It should look something like this

class UserProfileNoteRow(dataclass):
  id: str
  note: str
  created_at: datetime
  outdated: bool


class UserProfileNotesTable:
  def __init__(self):
    self._table_name = "user_profile_notes"

  def get_user_profile_notes(self, include_outdated: bool = false) -> list[UserProfileNoteRow]:
    pass


We have to create a new class in the models/user_context.py called UserProfileNote that will be the new model we will expose(same as the db model but without the outdated field)

We have to update the services/user_context.py file, for a smooth transition from one data model to the other let's keep the existing UserContextService abstract class and create a new UserProfileService class(not abstract) that will take in it's constructor a UserProfileNotesTable class. It should have a method to create a new user profile note, get the existing ones and update one to be outdated.


After that we should update our mcp api with the new tools that will basically expose the methods of the UserProfileService class


Remove any user context related tools and endpoints
